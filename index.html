OBJETIVO

Simular postes inteligentes de uma rua

01 / Conceito

Ideia do Projeto

Estrutura da Maquete

Consiste em duas casas e um galpão lado a lado em uma calçada. Em sua frente, há uma rua com postes de luz, que acendem e apagam baseado na luminosidade do ambiente.

Feito com materiais reutilizáveis e acabamento funcional

Automação Luminosa

O objetivo principal é acionar os LEDs localizados no topo dos postes automaticamente. O acionamento ocorre assim que o sensor de luminosidade detecta que o ambiente ficou escuro.

Economia de energia e acionamento dinâmico

04 / Circuito & Código

Projeto no Tinkercad & Código C++

Esquema do Circuito

- Simulação do circuito montado no Tinkercad -
• Grupo de Jumpers (fios) realizam a ligação do LDR ao Arduino e a Board - PORTAS RESPECTIVAS AOS RESISTORES-
• LEDs também são ligados através do mesmo método

Código C++

void loop() 
int leitura=0;

void setup()
{
    pinMode(7, OUTPUT);
    pinMode(6, OUTPUT);
    pinMode(2, OUTPUT);
    pinMode(3, OUTPUT);
    pinMode(4, OUTPUT);
    pinMode(5, OUTPUT);
    pinMode(A0, INPUT);
    Serial.begin(9600);//9600bps
}
void loop ()
{leitura = analogRead(A0);

Serial.println(leitura);
if(leitura < 40) { // se a luminosidade for menor que 40
    digitalWrite(6, HIGH);
    digitalWrite(7, HIGH);
    digitalWrite(2, HIGH);
    digitalWrite(3, HIGH);
    digitalWrite(4, HIGH);
    digitalWrite(5, HIGH);
} else { // se não
    digitalWrite(6, LOW); // apaga o LED
    digitalWrite(7, LOW);
    digitalWrite(2, LOW);
    digitalWrite(3, LOW);
    digitalWrite(4, LOW);
    digitalWrite(5, LOW);
} delay(100); // aguarda 100 milissegundos para uma nova leitura
}
